# STP — Skhoron Transport Protocol

Транспортный механизм, который определяет, через какую сеть отправлять запрос в зависимости от URL: обычный интернет (Clearnet), Tor или I2P, а затем устанавливает соединение через выбранную сеть.

Статус

Сеть| Статус
Tor| Работает. Использует SOCKS5 для подключения к локальному узлу Tor ("127.0.0.1:9050").
I2P| Работает. Использует SOCKS5 для подключения к локальному узлу "i2pd" ("127.0.0.1:4447").
Clearnet| Не реализован. Функция "stream_open()" возвращает явную ошибку.
Skhoron| Не реализован. Собственная сеть узлов Skhoron в рамках этого проекта не разрабатывается.

Сборка

make

Собирает исполняемый файл "./stp".

make test

Запускает 34 модульных теста для "router.c".

Использование

Проверка маршрута без подключения (по умолчанию):

./stp https://example.com

Фактическое подключение через Tor:

./stp --live http://xyz.onion

По умолчанию программа работает в режиме проверки маршрута ("dry-run"). Для реального подключения необходимо указать параметр "--live".
